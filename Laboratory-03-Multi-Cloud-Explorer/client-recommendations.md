## Client A – Startup Company

**Recommended Platform: AWS**

AWS would be a suitable platform for the startup because the company has a limited budget but expects rapid growth. AWS provides scalable services that allow the startup to begin with the resources it needs and increase capacity as the application gains more users. The startup can also use managed services to reduce the amount of infrastructure it needs to maintain itself. This flexibility can be useful for a young company whose requirements may change quickly. The startup could use **Amazon EC2** for computing, **Amazon S3** for object storage, and **Amazon RDS** for its relational database. AWS Lambda could also be considered for serverless application functions.

## Client B – University

**Recommended Platform: Microsoft Azure**

Microsoft Azure is the most appropriate choice for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's existing technologies, which can make the transition to cloud services easier. The university can migrate selected systems gradually instead of moving its entire infrastructure at once. Existing Microsoft knowledge among administrators can also help reduce the difficulty of managing the new environment. The university could use **Azure Virtual Machines** for Windows Server workloads, **Microsoft Entra ID** for identity management, **Azure Blob Storage** for data storage, and **Azure Virtual Network** for networking.

## Client C – AI Research Company

**Recommended Platform: Google Cloud**

Google Cloud would be an appropriate choice for the AI research company because the company develops artificial intelligence and machine-learning applications that require high-performance computing. Google Cloud provides services and infrastructure designed to support AI, machine learning, data processing, and scalable computing workloads. Its AI and data ecosystem can help researchers develop and deploy machine-learning applications. The company could use **Compute Engine** for high-performance computing workloads, **Vertex AI** for machine-learning development and deployment, and **Cloud Storage** for storing datasets and research files. **Google Kubernetes Engine** could also be used for containerized workloads.

## Client D – Global E-Commerce Company

**Recommended Platform: AWS**

AWS would be a strong choice for the global e-commerce company because it needs highly available infrastructure and automatic scaling for customers around the world. AWS provides services that can distribute workloads, handle changing traffic, and support applications across multiple geographic locations. This is important for an e-commerce company because traffic may increase significantly during promotions, holidays, or other busy periods. The company could use **Amazon EC2** for computing, **Elastic Load Balancing** to distribute incoming traffic, and **EC2 Auto Scaling** to automatically adjust capacity. **Amazon S3** and **Amazon RDS** could also support storage and database requirements.

## Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | **AWS** | Broad services, scalability, and flexibility for growing applications |
| Enterprise Organization | **AWS** | Large service portfolio and extensive enterprise capabilities |
| Microsoft Environment | **Azure** | Strong integration with Microsoft's technologies |
| AI / Machine Learning | **Google Cloud** | Strong AI, ML, and data capabilities |
| Kubernetes Deployment | **Google Cloud** | Strong Kubernetes ecosystem and GKE |
| Global Web Application | **AWS** | Global infrastructure and scalable application services |
