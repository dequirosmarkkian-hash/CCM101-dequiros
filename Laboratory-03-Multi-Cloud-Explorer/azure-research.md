
# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides services for computing, storage, networking, databases, identity management, security, analytics, artificial intelligence, and application development. Azure is particularly useful for organizations that already use Microsoft technologies because it can integrate with existing Microsoft environments. Instead of maintaining all infrastructure on physical servers, organizations can use Azure resources through the cloud. Azure supports both small applications and large enterprise environments.

## Global Infrastructure

Azure provides a global cloud infrastructure organized into geographic regions and availability zones. These locations allow organizations to deploy applications and services in different parts of the world. Using multiple locations can help organizations improve application availability and reduce latency for users. Azure's global infrastructure also gives businesses options when they need to consider geographic requirements, performance, reliability, or data residency.

## Cloud Management Console

The Azure Portal is Microsoft's web-based management interface for Azure. It allows administrators and developers to create, configure, monitor, and manage cloud resources. Users can access virtual machines, storage accounts, networks, databases, identity services, and many other Azure resources through the portal. The graphical interface provides a centralized location for managing an organization's Azure environment.

## Four Core Services

1. **Azure Virtual Machines** – Provides virtual servers for running applications and operating systems.
2. **Azure Blob Storage** – Provides object storage for files and unstructured data.
3. **Azure Virtual Network** – Provides networking capabilities for Azure resources.
4. **Microsoft Entra ID** – Provides identity and access management.

## Three Advantages

One major advantage of Azure is its strong integration with Microsoft technologies. This makes it suitable for organizations that already use Windows Server, Microsoft 365, and Active Directory-related technologies. Another advantage is its enterprise-oriented cloud services. Azure also provides scalable infrastructure that can be adjusted as an organization's requirements change.

## Typical Enterprise Use Cases

Azure can be used for Windows Server migration, enterprise application hosting, database systems, backup and disaster recovery, hybrid cloud environments, and business applications. Organizations using Microsoft 365 and existing Microsoft identity systems can also use Azure to extend their infrastructure into the cloud. Universities, businesses, government organizations, and other enterprises can use Azure to modernize existing infrastructure while continuing to work with Microsoft technologies.
