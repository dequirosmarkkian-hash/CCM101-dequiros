
# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a major cloud computing platform that provides many different services for organizations and developers. AWS allows users to access computing resources, storage, databases, networking, security, analytics, and other technologies through the cloud instead of purchasing and maintaining all physical infrastructure themselves. AWS is useful for businesses of different sizes because resources can be created and adjusted based on their requirements. It can support websites, mobile applications, enterprise systems, databases, data analytics, and artificial intelligence workloads.

## Global Infrastructure

AWS has a large global infrastructure organized into geographic Regions and Availability Zones. Regions are separate geographic areas where AWS provides cloud services, while Availability Zones provide separate locations within a Region. This structure allows organizations to deploy applications in different locations and design systems for availability and resilience. Businesses can select locations that are appropriate for their customers, performance requirements, and operational needs. AWS's global infrastructure is one reason it can support applications used by organizations and customers around the world.

## Cloud Management Console

The AWS Management Console is a web-based interface that allows users to manage AWS resources and services. Through the console, users can create virtual machines, configure storage, manage identities and permissions, monitor resources, and access many other AWS services. The console provides a graphical interface that can make cloud management easier for beginners compared with using only command-line tools. It also allows administrators to view and manage resources from a central location.

## Four Core Services

1. **Amazon EC2** – Provides virtual servers that can run applications and operating systems.
2. **Amazon S3** – Provides object storage for files, data, backups, and other objects.
3. **Amazon VPC** – Provides networking capabilities for creating isolated cloud networks.
4. **AWS IAM** – Manages users, roles, permissions, and access to AWS resources.

## Three Advantages

First, AWS provides a very broad range of cloud services that can support many different technical requirements. Second, its global infrastructure allows organizations to deploy applications in multiple geographic locations. Third, AWS provides scalable resources, meaning businesses can increase or decrease resources as their workloads change.

## Typical Enterprise Use Cases

AWS can be used for hosting websites and mobile applications, storing organizational data, running databases, creating backup and disaster recovery systems, supporting e-commerce platforms, and developing artificial intelligence applications. Enterprises can also use AWS for analytics and large-scale data processing. Because AWS provides many different services, organizations can combine multiple services to build complete cloud-based systems according to their business requirements.
