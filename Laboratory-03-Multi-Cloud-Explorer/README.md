
# Laboratory-03-Multi-Cloud-Explorer


## Mission Overview

This laboratory focuses on exploring and comparing three major cloud computing
platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud
Platform (GCP). The activity examines the main services offered by each
provider and determines which platform is appropriate for different business
requirements.

## Mission Objectives

- Explore AWS, Azure, and GCP.
- Research the core services of each cloud provider.
- Compare equivalent cloud services.
- Recommend suitable cloud platforms for different clients.
- Create a multi-cloud decision matrix.
- Investigate a Linux environment using KillerCoda.
- Document the results in a GitHub repository.

## Cloud Platforms Explored
### Amazon Web Services (AWS)

AWS is a major cloud computing platform that provides services for computing,
storage, databases, networking, security, and other cloud workloads.

### Microsoft Azure

Microsoft Azure is Microsoft's cloud computing platform. It provides
computing, storage, networking, databases, identity, security, and other
enterprise cloud services.

### Google Cloud Platform (GCP)

Google Cloud Platform provides cloud services for computing, storage,
networking, databases, artificial intelligence, machine learning, and
Kubernetes.
