# Laboratory 05 – Cloud Data Engineer

## Mission Overview

In this laboratory activity, I explored cloud storage technologies and deployed an S3-compatible object storage server using MinIO and Docker. The goal was to understand the differences between Block Storage, File Storage, and Object Storage and to create a working object storage environment.

## Objectives

* Differentiate between Block, File, and Object Storage.
* Deploy MinIO using Docker.
* Access the MinIO Web Console through port forwarding.
* Create an object storage bucket.
* Upload a sample file to the bucket.
* Document the deployment process using Markdown.
* Organize the laboratory work in a GitHub cloud computing portfolio.

## Tools Used

* KillerCoda Playground
* Ubuntu
* Docker
* MinIO
* GitHub
* Web Browser
* Markdown

## Skills Learned

Through this laboratory, I learned how different cloud storage technologies are used for different purposes. I also learned how to deploy an S3-compatible storage service using Docker, access a cloud service through a specific port, create a storage bucket, and upload objects through a web interface.

I also improved my skills in using the Linux command line, Docker commands, GitHub repository organization, and technical documentation.
